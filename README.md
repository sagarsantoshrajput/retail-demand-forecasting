# Retail Demand Forecasting & Inventory Optimization

Automated analytics platform for retail and supply chain teams: time-series forecasting of store- and
department-level demand from historical sales, promotions and seasonality, generating a 30-day forecast
and a what-if price simulator for inventory managers.

**Stack:** Python - SQL - DuckDB (BigQuery/Snowflake-compatible SQL) - dbt - Facebook Prophet - LightGBM - Streamlit

Work in progress - built over a 4-week plan (see `docs/GIT_WORKFLOW.md`).
