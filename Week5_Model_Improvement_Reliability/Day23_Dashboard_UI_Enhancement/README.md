\# Day 23 – Dashboard UI Enhancement



\## Objective

Enhance the Retail Demand Forecasting Streamlit dashboard to improve usability, visualization, and presentation of business insights.



\## Enhancements Implemented



1\. \*\*Improved KPI Cards\*\*

&#x20;  - Average daily sales

&#x20;  - Average selling price

&#x20;  - Historical units sold

&#x20;  - 30-day forecast demand



2\. \*\*Interactive Filters\*\*

&#x20;  - Product category selection

&#x20;  - Store selection

&#x20;  - Item selection

&#x20;  - Historical date-range filter



3\. \*\*Enhanced Visualizations\*\*

&#x20;  - Historical sales trend

&#x20;  - Forecast versus actual demand

&#x20;  - Interactive Plotly charts



4\. \*\*What-if Analysis\*\*

&#x20;  - Simulate selling-price changes.

&#x20;  - Compare baseline and scenario forecasts.

&#x20;  - Display projected demand changes.



5\. \*\*Organized Dashboard Layout\*\*

&#x20;  - Overview

&#x20;  - What-if Analysis

&#x20;  - Model Accuracy

&#x20;  - Documentation



6\. \*\*Visual Improvements\*\*

&#x20;  - Improved spacing and layout

&#x20;  - Styled KPI cards

&#x20;  - Clear section headings

&#x20;  - Better chart presentation



\## Technologies Used

\- Python

\- Streamlit

\- Plotly

\- Pandas

\- NumPy

\- DuckDB

\- LightGBM



\## Files

\- `app.py` – Enhanced Streamlit dashboard application.



\## Execution

Run from the project root:



```bash

python -m streamlit run streamlit\_app/app.py

```



\## Outcome

The dashboard provides a cleaner and more interactive interface for exploring historical sales, demand forecasts, model accuracy, and price-change scenarios.
